⚠️ 랜선 색상을 반드시 확인하세요. 파란 선은 외부 공인 IP이며 복합기에 연결 불가합니다.

업무툴 세팅

Google Workspace
1 초기 비밀번호 변경
2 프로필 사진 설정
3 이메일 서명 설정 (가이드 링크 참고)
4 2FA 설정: 계정관리 → 보안 → 2단계 인증
🔐 보안 강화를 위해 2단계 인증(2FA)은 필수입니다. 로그인 직후 바로 설정하세요.
Notion
  • 접속 URL: 노션 바로가기 ↗
  • 가입: 초대 링크는 입사 안내 메일에 포함되어 있습니다.
ℹ️ 접속 후 팀스페이스 및 그룹스를 확인해 주세요.
Slack
1 가입: 초대 링크는 입사 안내 메일에 포함되어 있습니다.
2 프로필 설정 — 이름 / 직책 / 프로필 사진
3 #ga-helpdesk 채널 (GA 관련 모든 문의)
📘 슬랙 프로필 설정 가이드 → PPT 상세 가이드 탭 참고
그룹웨어
  • 접속 URL: 그룹웨어 바로가기 ↗
  • 초기 로그인: 계정 정보는 입사 안내 메일에 포함되어 있습니다.
  • 로그인 후 위임전결규정_기준표 확인 (기안 양식 링크 내 별도 문서)

오피스 이용

회의실 현황
위치개수구성예약 방법
21층 코너스페이스 9개 미팅룸 8개 + 대회의실 1개 Google Calendar
29층 5개 일반 회의실 Google Calendar
28층 1번 스튜디오 1개 대회의실 용도 유캔북미 예약 / PS팀 문의
회의실 사용 기준
  • 21층 운영 시간: 08:00 ~ 22:00
  • 29층: HDMI 연결 후 사용
  • 일정 제목 형식: [팀명] + 미팅대상
  • 예약 후 10분 미사용 시 노쇼 처리
⏰ 예약 후 10분 내에 입실하지 않으면 자동 노쇼 처리되어 타 팀이 사용할 수 있습니다.
28층 스튜디오 이용 규칙
  • 촬영 일정이 항상 선순위
  • 정기 예약 불가
  • 사용 후 원상 복구 필수
🎬 스튜디오 촬영 일정과 충돌 시 회의실 사용이 취소될 수 있습니다. 사전에 PS팀에 확인하세요.

1순위 주요 외부 미팅 · 경영 이벤트
2순위 CXO · 실장 리더 위클리
3순위 면접 (4번 회의실 09:00~10:00 / 17:00~19:00 고정)
4순위 팀 위클리 · 1on1
21층 코너스페이스
  • 입장 시 사원증 필수
  • 공용 라운지 · BAR 사용 불가
  • 미팅룸 · 폰부스 사용 불가
라운지 및 분리수거
종류배출 방법

재활용라운지 재활용 쓰레기통 (개인 쓰레기통 배출 불가)

  • 등기 발송: GA 자리 앞 발송함
  • 수거 일정: 월 · 수 · 금 16시 이후 일괄
택배
  • 보관함: 28층 출입문 앞 / 29층 라운지 반대편

  • FedEx: 발송대행 가능 (발송 양식 ↗ 작성 후 GA 담당자 전달)
  • DHL / EMS: 개별 접수 및 결제

  • 취소 문의: 1544-1020
명함 제작
  • 명함 제작 사이트 ↗
  • 코드 : sandbox
  • 부서1 = 상위 조직
  • 부서2 = 주 조직
  • 직책 = Flex 기준으로 입력
법인차량
  • 키 수령: 28층 GA 자리
  • 차량: 소나타 / 카니발
  • 만 21세 이상 + 운전면허 소지자
  • 업무 목적만 사용 가능
  • 유류대 · 세차비: 개인 법인카드 사용
🚗 사고 발생 시: 사진 촬영 → 보험사 접수 → GA 보고. 인명/분쟁 시 112 신고 후 GA 연락
